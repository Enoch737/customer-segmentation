## Project Overview

This project performs customer segmentation using **unsupervised clustering techniques** on a grocery firm's customer data. By analyzing behavior and demographic data, the goal is to group customers into segments to enable more personalized marketing and better product targeting.

---

## Dataset

- **Source:** [Kaggle - Customer Personality Analysis](https://www.kaggle.com/imakash3011/customer-personality-analysis)
- **Description:** The dataset contains demographic and transactional data for customers of a grocery store chain.
- **Key Fields:** Income, Age, Education, Spending habits, Family structure

---

## Project Highlights

-  Data Cleaning and Feature Engineering
-  Dimensionality Reduction using PCA
-  Clustering with KMeans, Agglomerative, and DBSCAN
-  Model Evaluation using Silhouette Score and Elbow Method
-  Cluster Profiling for strategic business insights
